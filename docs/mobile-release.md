# Mobile release — EDUVERSE-UZ

The React/Vite client is the shared responsive product. It is a full PWA:
installable on Android, iPhone, iPad, laptops, and interactive boards — no APK
or App Store download is required for daily use.

## What the user gets

| Device           | How to install                                      | What it does                                        |
|------------------|-----------------------------------------------------|------------------------------------------------------|
| Android phone    | Chrome → Install app → home screen (or the **Установить приложение** button in the top bar) | Full platform: QR login, online lessons with camera/mic/screen share, topics & 3D, attendance |
| iPhone / iPad    | Safari → Share → *Add to Home Screen*               | Same, with camera/mic permission for online lessons  |
| Android tablet   | Same as Android                                     | Layout adapts (sidebar → drawer, bottom navigation)  |
| Laptop / desktop | Any browser, or install via the button              | Full platform + projector-friendly board             |

## Install button

The top bar (and login screen) shows **Установить приложение**:

- On Android Chrome it triggers the native install prompt directly.
- On iOS it shows exact illustrated steps (Share → Add to Home Screen).

## Icons & metadata

Generated by `scripts/generate-icons.mjs` (no dependencies):

```
public/icon-192.png  public/icon-512.png  public/icon-maskable-512.png
public/apple-touch-icon.png  public/manifest.webmanifest  public/sw.js (offline shell)
```

`index.html` carries `apple-mobile-web-app-capable`, `apple-mobile-web-app-title`,
`theme-color`, `viewport-fit=cover` and safe-area paddings for notches.

## Publishing to the stores (when you decide)

See `docs/vercel-deployment.md` §7 — PWABuilder for Google Play and App Store,
or Capacitor (`pnpm exec cap add android/ios`) for a fully native build with
push notifications and background WebRTC.

If you ship to stores, prepare:

- App Store / Play Store icons and screenshots of the real installed PWA.
- A privacy policy and terms URL on your Vercel domain.
- Camera / microphone / screen-share usage descriptions (WebRTC lessons).
- Android `INTERNET`, camera/mic permissions and deep links.
- Crash reporting and analytics only with user consent.

Do not use the local demo database or demo accounts in a store build; point
the app at your Vercel deployment URL and use school-provisioned accounts.
