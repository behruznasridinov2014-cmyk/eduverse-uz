# Дизайн-система (как есть)

**Важно:** фактический стиль — не фиолетово-синий. Сейчас это тёплая «шампань»: кремовый фон, золотой акцент, светло-голубой как второй цвет. Фиолетового в интерфейсе нет (`--tone-violet` = `#B8955A`, тоже золото).

## Токены (`src/theme.css`)
- Фон: `--bg #F6F1E7`, `--bg-2 #FBF8F2`; карточки полупрозрачные `--surface rgba(255,255,255,.72)` + `backdrop-filter` (стекло).
- Акцент: `--ev-primary #B8955A` (золото), hover `#A6844C`; второй — `--lavender #8FC8EE`, `--tone-blue #4BA3DB`.
- Текст: `#1E2633 / #4B5566 / #7D8696`. Статусы: ok `#2E9E6E`, warn `#C98A1E`, bad `#D2475A`.
- Цвет раздела (`tone-*` в меню): урок — синий, 3D, посещаемость — зелёный, ДЗ — оранжевый, книги, доска — розовый.
- Радиусы: 22 / 18 / 14 / 10 px.
- Шрифты: `DM Sans` (интерфейс), `Literata` (заголовки, серифный), моно для кода.
- Анимации: `motion.css` (плавная смена языка, появление блоков), стекло — `glass.css`.
- Компоненты: свои (`Panel`, `SectionHead`, `Kpi`, `glass-nav.tsx`, `nav-icons.tsx`) + Radix (`components/ui`).

## Проблемы
1. Слои CSS спорят: `app.css` → `theme.css` (дважды переопределяет палитру) → `glass.css`/`motion.css`. Комментарий в шапке `theme.css` устарел.
2. Нет единого списка компонентов: кнопки/карточки повторяются по файлам.
3. Тёмная тема есть частично.

## Решение, которое нужно от владельца
Оставить тёплую золотую палитру (текущая) или вернуться к фиолетово-синей (как в описании бренда). Не смешивать.
