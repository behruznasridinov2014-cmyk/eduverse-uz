# Идеи, которые отличают EDUVERSE (на основе того, что уже есть)

1. **«Урок за 1 клик» для учителя** — тема по темпу учебника (`course_pace`) → 7 этапов + 3D + тест готовы автоматически. Уже 80% есть в `lesson-engine.ts`.
2. **Ежедневный отчёт родителю в Telegram** в 19:00: пришёл/нет, оценки, ДЗ на завтра. Outbox уже есть.
3. **Повторение по ошибкам** — тренажёр (`trainer_results`) сам подбирает задачи по темам, где ученик ошибся.
4. **Карта класса на доске** — во время урока учитель видит, кто на каком этапе и кто ошибся (`lesson_stage_progress` + `lesson_live`).
5. **Проверка тетради по фото с подсказками** — Gemini подсвечивает строки с ошибкой, оценку ставит учитель.
6. **Офлайн-пакет темы** — скачать урок, 3D и тренажёр на телефон, синхронизировать позже (важно для регионов).
7. **Виртуальные лабораторные по программе** — `chem-lab`, `physics-lab` привязать к темам курса и выдавать как ДЗ с отчётом.
8. **Рейтинг класса и сезон четверти** — уже есть `trainer/rating`; добавить командные цели класса, без давления на слабых.
9. **Паспорт ученика** — один экран за год: оценки, посещаемость, освоенные темы; для родителей и перевода в другую школу.
10. **Сводка для управления образования** — сравнение школ по посещаемости и прогрессу по программе, без личных данных учеников.
