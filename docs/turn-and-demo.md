# TURN-сервер и демо-школа

## 1. TURN для онлайн-уроков
Код готов: сервер сам выдаёт ключи на `/api/ice-servers`. Нужно только добавить переменные в Vercel
(Project → Settings → Environment Variables → Production) и сделать Redeploy. Ключи в файлы не писать.

Вариант A — Cloudflare Realtime TURN (проще всего, платится по трафику):
- `CLOUDFLARE_TURN_KEY_ID`
- `CLOUDFLARE_TURN_API_TOKEN`

Вариант B — любой свой или купленный TURN (Metered, Twilio, свой сервер на VPS):
- `TURN_URLS` — адреса через запятую, например `turn:turn.example.com:3478,turns:turn.example.com:443?transport=tcp`
- `TURN_USERNAME`
- `TURN_CREDENTIAL`

Проверка: войти учителем, открыть онлайн-урок; ученик подключается с телефона через мобильный интернет
(не через школьный Wi-Fi) и должен видеть и слышать учителя. Без TURN такое соединение у части учеников не поднимется.

## 2. Демо-школа для показа
Скрипт `scripts/seed-demo-school.mjs` создаёт школу «EDUVERSE Demo School №24»: директор, учитель, 3 класса
(30 выдуманных учеников), давомат за 5 дней, темы, физика 7 класса с шестью пройденными темами,
две домашки с оценками.

ВАЖНО: запускать только на ОТДЕЛЬНОЙ демо-базе (например, ветка Neon «demo»), не на рабочей. Скрипт берёт
`DATABASE_URL` из файла `.env` в корне проекта.

```bash
node scripts/seed-demo-school.mjs
```

Пароль для всех демо-аккаунтов генерируется случайно и печатается один раз в конце
(или задайте свой: `DEMO_PASSWORD=...`). Логины: `demo_director`, `demo_teacher`, `demo_admin`,
`demo_student_b_1` … `demo_student_b_12`.
Повторный запуск безопасен: ничего не удаляет и не меняет пароли уже созданных аккаунтов.
